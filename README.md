# MGT155FinalProject
Code Files + Jupyter Notebooks for our MGT 155 Final Project

This repo has the code for our MGT 155 final project. The project looks at two different operations problems and uses simulation to compare different decisions.

PART 1: 
The first part is about airline overbooking. I used booking, no-show, and compensation data to figure out how many tickets Southwest should sell for a 250-seat flight from San Diego to Boston. I first looked at the historical data, then used regression and a Monte Carlo simulation to test different booking levels and compare expected profit, risk, and the average number of passengers bumped.

PART 2: 
The second part is a bank simulation built with SimPy. The model follows customers as they either go to the ATM, go directly to the cashiers, or go from the ATM to a cashier. I used the simulation to calculate cashier utilization, average queue lengths, and the time customers spend in the bank. I also compared two possible improvements: adding a sixth cashier or training the current cashiers so service times are shorter.

Overall, this project was about using data and simulation to make better business decisions
